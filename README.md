# Hanover Tecnologia - Site Institucional

Este é o projeto web completo e profissional da empresa Hanover Tecnologia.
Desenvolvido com HTML5, CSS3, Flexbox e JavaScript Puro.

## Como Executar

1. Extraia o conteúdo deste arquivo `.zip`.
2. Abra a pasta `Projeto-Hanover` no **Visual Studio Code**.
3. Instale a extensão "Live Server".
4. Clique com o botão direito no `index.html` e selecione "Open with Live Server".

## Publicação na Vercel

1. Envie a pasta para um repositório no GitHub.
2. Acesse `vercel.com` e importe o repositório.
3. Clique em "Deploy". (Nenhuma configuração extra é necessária).
